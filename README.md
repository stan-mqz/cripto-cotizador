# Cripto Cotizador / Crypto Quote

  

Real-time Cryptocurrency Quote. Check the current price of major cryptocurrencies against selected fiat currencies.

  

Cotizador de Criptomonedas en tiempo real. Consulta el precio actual de las principales criptomonedas frente a monedas fiat seleccionadas.


[Live Demo](https://cripto-react-app-ts.netlify.app/)

![image](https://github.com/user-attachments/assets/ec3bbb51-7a29-4a03-8f2e-ec24ad863ddf)


## 🌐 English

  

### Description

  

This application allows you to select a cryptocurrency and a fiat currency to get the current quote, the highest and lowest price of the day, the variation in the last 24 hours, and the last update. The data is obtained from the public API of [CryptoCompare](https://min-api.cryptocompare.com/).

  

### Features

  

- Selection of popular cryptocurrencies (top 20 by market capitalization)

- Selection of fiat currencies: US Dollar (USD), Mexican Peso (MXN), Euro (EUR), British Pound (GBP)

- Display of current price, daily highs and lows, percentage variation, and last update

- Loading indicator while fetching data

- Error handling and form validation

  

### Technologies Used

  

-  [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)

-  [Vite](https://vitejs.dev/) for development and build

-  [Zustand](https://zustand-demo.pmnd.rs/) for global state management

-  [Axios](https://axios-http.com/) for HTTP requests

-  [Zod](https://zod.dev/) for data validation



  

### Installation

  

1. Clone the repository:

```bash

git clone https://github.com/stan-mqz/cripto-cotizador.git

cd cripto-cotizador

```

2. Install dependencies:

```bash

npm install

```

  

### Development Usage

  

Start the development server:

```bash

npm  run  dev

```

Open [http://localhost:5173](http://localhost:5173) in your browser to view the application.

  

### Production Build

  

Generate optimized files for production:

```bash

npm  run  build

```

  

Preview the production build locally:

```bash

npm  run  preview

```

## 🌐 Español

  

### Descripción

  

Esta aplicación permite seleccionar una criptomoneda y una moneda fiat para obtener la cotización actual, el precio más alto y más bajo del día, la variación en las últimas 24 horas y la última actualización. Los datos se obtienen de la API pública de [CryptoCompare](https://min-api.cryptocompare.com/).

  

### Características

  

- Selección de criptomonedas populares (top 20 por capitalización de mercado)

- Selección de monedas fiat: Dólar estadounidense (USD), Peso mexicano (MXN), Euro (EUR), Libra esterlina (GBP)

- Visualización de precio actual, máximos y mínimos diarios, variación porcentual y última actualización

- Indicador de carga mientras se obtienen los datos

- Manejo de errores y validación de formularios
